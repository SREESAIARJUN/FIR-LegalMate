# FIR-LegalMate

FIR-LegalMate is a tool designed to assist police officers in drafting First Information Reports (FIRs). It streamlines the FIR creation process, ensuring accuracy and efficiency. ([firlegalmate.streamlit.app](https://firlegalmate.streamlit.app/)

**Note:** This tool is designed to assist police officers in drafting FIRs. Always consult with legal experts for final verification.

## Features

- **User-Friendly Interface:** Simplifies the FIR drafting process.
- **Guided Input:** Ensures all necessary information is captured accurately.
- **Real-Time Validation:** Minimizes errors by validating inputs as you type.

## Demo

Experience FIR-LegalMate in action: [https://firlegalmate.streamlit.app/](https://firlegalmate.streamlit.app/)

## Installation

To set up FIR-LegalMate locally:

1. **Clone the Repository:**

   ```bash
   git clone https://github.com/SREESAIARJUN/FIR-LegalMate.git
   cd FIR-LegalMate
   ```

2. **Install Dependencies:**

   Ensure you have Python installed. Then, install the required packages:

   ```bash
   pip install -r requirements.txt
   ```

3. **Run the Application:**

   ```bash
   streamlit run app.py
   ```

   Access the application at `http://localhost:8501` in your browser.

## Usage

1. **Launch the Application:** Follow the installation steps to run the app locally or access the [online demo](https://firlegalmate.streamlit.app/).

2. **Input Details:** Fill in the required fields as prompted.

3. **Generate FIR:** Once all information is provided, the tool will generate a draft FIR for review.
